Política de Privacidade

oNiguel tradutor · Última atualização: 10 de outubro de 2026

Quem usa esta aplicação

O oNiguel tradutor é um script pessoal, usado apenas pelo dono do canal de YouTube oNiguel, no seu próprio computador. Não está disponível ao público.

Que dados acede

Com autorização da conta Google do dono do canal, o script acede, através da YouTube Data API, apenas a:

  • títulos, descrições, idioma e traduções dos vídeos do próprio canal;
  • a lista de faixas de legendas dos vídeos do próprio canal, só para verificar se existem legendas em português.

Não acede a dados de espectadores, comentários, mensagens, contactos ou dados de pagamento.

Para que são usados

O título e a descrição de cada vídeo são enviados para o serviço de tradução DeepL e as traduções são guardadas no próprio vídeo, na secção de idiomas do YouTube. Não há outra utilização.

Onde ficam guardados

A autorização da conta Google e um registo das traduções ficam guardados apenas no computador do dono do canal. Não existe servidor, base de dados online, publicidade nem partilha com terceiros, para além do envio do texto à DeepL para tradução.

Utilização limitada

O uso e a transferência de informação recebida das APIs da Google cumprem a Política de Dados do Utilizador dos Serviços de API da Google, incluindo os requisitos de Utilização Limitada.

Como retirar o acesso

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions.

Privacy Policy

oNiguel tradutor · Last updated: 10 October 2026

Who uses this application

oNiguel tradutor is a personal script used only by the owner of the oNiguel YouTube channel, on his own computer. It is not available to the public.

What data it accesses

With authorisation from the channel owner's Google account, the script uses the YouTube Data API to access only:

  • titles, descriptions, language settings and translations of the channel's own videos;
  • the list of caption tracks of the channel's own videos, only to check whether Portuguese captions exist.

It does not access viewer data, comments, messages, contacts or payment data.

How the data is used

Each video's title and description are sent to the DeepL translation service and the translations are saved on the video itself, in YouTube's languages section. There is no other use.

Where the data is stored

The Google authorisation and a log of translations are stored only on the channel owner's computer. There is no server, online database, advertising or sharing with third parties, other than sending text to DeepL for translation.

Limited Use

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
